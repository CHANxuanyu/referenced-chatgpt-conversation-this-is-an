# AI-native 个人知识库：产品定义与设计证据

这是一个本地优先个人知识库产品的完整定义档案，包含：

- Canonical 终局产品设计文档；
- 知识群、层级、连续阅读、关系网络、AI 查询、知识形成与 Library 入口等专项合同；
- 用户可见信息架构、产品语言与复杂度披露合同；
- 产品决策审阅稿、需求—旅程—验收—设计证据追踪矩阵；
- 真实内容夹具、规模压力夹具与 Ardot 视觉审计证据；
- 历史版本和迁移材料，用于追溯产品从 Cognitive OS 收敛回知识库的过程。

现行产品定义以 [`outputs/ai-native-knowledge-base/canonical/AI-native-个人知识库-终局产品设计文档-v6.0.md`](outputs/ai-native-knowledge-base/canonical/AI-native-个人知识库-终局产品设计文档-v6.0.md) 为唯一 Canonical。文档权威与附录关系见 [`outputs/AI-native-个人知识库-文档权威注册表-v1.0.md`](outputs/AI-native-个人知识库-文档权威注册表-v1.0.md)。

## 仓库结构

- `outputs/ai-native-knowledge-base/` — 知识库产品文档主体
  - `canonical/` — 唯一现行产品定义（v6.0）
  - `contracts/` — 现行专项合同（Active Appendix）
  - `decisions/` — 决策伴随文档
  - `evidence/` — 审计、追踪矩阵等设计证据
  - `fixtures/` — 真实内容与设计数据夹具
  - `migration-queue/` — 待迁移旧合同，按注册表第 3 节分 5 组
  - `experimental/` — 实验性语义附录
  - `history/` — v3–v5 历史产品定义
- `outputs/design-audit-ardot/` — Ardot 设计审计文档与逐屏截图证据
- `outputs/visual-directions/` — 视觉方向探索
- `outputs/personal-cognitive-os/` — Cognitive OS 历史文档
- `outputs/project-continuity/` — Project Continuity 历史文档
- `design-stack.md` — 设计资产工程选型清单

当前阶段是产品定义与设计证明，不是实现、部署或可点击原型。
